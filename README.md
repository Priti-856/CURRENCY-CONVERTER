# CURRENCY-CONVERTER
A responsive and user-friendly Currency Converter web application that allows users to convert one currency into another using real-time exchange rates.

##Features:
-> Convert between multiple international currencies
-> Fetches real-time exchange rates using Currency API
-> Displays country flags based on selected currencies
-> Swap currencies instantly
-> Responsive design for desktop and mobile devices
-> Fast and lightweight interface

##Technologies used: 
- HTML5
- CSS3
- JavaScript
- Fetch API
- Currency API
- Flags API

**How It Works**

1. Enter the amount you want to convert.
2. Select the source currency.
3. Select the target currency.
4. Click **Get Exchange Rate**.
5. The application fetches the latest exchange rate and displays the converted amount.
